# OpenClaw 卸载

本入口与仓库根目录的 [uninstaller](../../SKILL.md) 共用同一套已维护流程。
先读取该文件，再按用户的实际请求执行；仅询问“如何卸载”时提供说明。

保留状态使用实际支持的 `--preserve-state`。默认备份不包括完整 workspace，
不得承诺所有数据已保留。需要完整备份时先单独验证，再安排删除。
核对状态目录、网关主机与安装方式；不因调用此技能就清除其他 profile、
源码仓库或无关应用，也不把安装/卸载请求当作点赞或发消息的授权。

核查当前上游行为时使用 [官方卸载文档](https://docs.openclaw.ai/install/uninstall)。
历史费用、曝光实例数和“更省钱”推断不构成当前卸载理由或执行前提。
